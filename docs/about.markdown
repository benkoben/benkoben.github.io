Hello my name is Ben. I love technology and stubbornly (for good and bad) doing things myself.
I use this site to write about topics I find interesting and to document projects I am working on.

# Why this site?

I often find myself in a position where a have created something I think is cool, but dont share it with others. I also often dont write down what I have been working on and how I solved certain problems and then forget about it. My intention with this site is to address both this situations. Writing down stuff for future-me and (for anyone who's interested) sharing knowledge at the same time.
